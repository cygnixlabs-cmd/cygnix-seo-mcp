What the tools do

Each tool returns a clean table or checklist your assistant can act on right away.

Live Search Console

Connect Google once with one click (read-only). Then gsc_search_analytics, gsc_find_cannibalization and gsc_inspect_url pull clicks, impressions, positions and index status live.

AI-search visibility (AEO)

check_ai_search_readiness scores a page 0-100. It checks whether OAI-SearchBot, Claude-SearchBot, PerplexityBot, Bingbot and Googlebot can reach it, plus schema, answer-ready structure and server-rendered text.

llms.txt checker

check_llms_txt validates /llms.txt against the llmstxt.org format and writes a starter file if you don't have one.

Keyword clustering and intent

cluster_keywords groups a list into pages with a pillar keyword. classify_search_intent tags each keyword as informational, commercial, transactional or navigational.

Titles, metas and briefs

check_title_meta scores pixel truncation and CTR hooks. content_brief_outline builds an H2 outline, questions and an on-page checklist.

White-label PDF reports

Agency plan: create_white_label_report turns any result into a client-ready PDF with your logo, colours and agency name.

FAQ

Which apps does it work with?

Claude (custom connectors, Claude Code), ChatGPT (developer mode connectors), Cursor, VS Code and any remote MCP client. See Connect.

What counts as a call?

One tool run. Quotas reset on the 1st of each month (UTC). When you hit the limit, the assistant gets a clear message with an upgrade link.

Is my Search Console data stored?

No. We keep only an encrypted, revocable refresh token. Data is fetched when a tool runs and isn't kept. Privacy

Is there a local version?

Yes. npx cygnix-seo-mcp runs the five core tools free on your machine over stdio. The hosted version adds Search Console, AEO checks and reports.
