1. What we collect

  • Account data: your email address, plan, account status, and when your account and keys were created and last used.
  • API keys: stored only as one-way SHA-256 hashes, plus the first 12 characters for display. We can't recover a lost key; you rotate it instead.
  • Usage metering: the number of tool calls per key per month, and short-lived per-minute counters, used for quotas, rate limits and billing.
  • Client name: the name your AI app reports when it connects (for example openai-mcp or claude-ai) and the name an app registers for sign-in. We keep the latest one per key or connected app, to show messages that fit that app (for example, no pricing inside ChatGPT). The browser/app user-agent string is read per request and not stored.
  • Tool inputs and outputs: processed in memory to produce the result and not stored. The exception is white-label PDF reports you create on purpose, which we store for 30 days so the private link works.
  • Google Search Console (optional, coming soon): when available and you connect it, we store an OAuth refresh token encrypted with AES-256-GCM and the granted scope (webmasters.readonly). Search Console data is fetched when you run a tool and not retained.
  • Branding (Agency): the agency name, logo URL, colours, website and footer text you provide.
  • Billing:
  • Subscriptions (PayPal, Whop, Stripe): we receive a subscription ID, customer ID, plan and status from the provider.
  • One-time payments (crypto invoices through NOWPayments, Payoneer, PayPal.me, direct crypto transfer): we keep an order record (order reference, plan, amount in USD, status, dates), the gateway's payment ID, and any payment reference you submit (for example a PayPal transaction ID or a blockchain transaction hash).
  • We never see or store card numbers or bank logins. Blockchain transactions are public by nature; a transaction hash you give us links your order to that public transaction.
  • Technical logs: our host (Cloudflare) processes IP addresses and request metadata for security and abuse prevention. We use IP addresses to rate-limit sign-ups and payment-reference submissions.
  • Public pages you ask us to check: the AEO and llms.txt tools fetch the public URLs you supply and identify themselves as CygnixSEO-MCP/1.0.

We do not use cookies or analytics trackers on mcp.cygnixlabs.com. [Update if analytics is added.]

To provide and secure the Service, enforce plan limits, process payments and activate plans, answer support and billing requests, send essential service emails, and prevent abuse. We do not sell personal data, use it for advertising or profiling, or use your inputs, outputs or Search Console data to train AI models.
