Connect in 2 minutes

You need the server URL https://mcp.cygnixlabs.com/mcp and an API key. Get a free key if you don't have one yet.

Claude (web and desktop)

  1. Open Settings → Connectors and click Add custom connector.
  2. Name it Cygnix SEO and set the URL to https://mcp.cygnixlabs.com/mcp.
  3. Under Authentication choose Sign in now (OAuth). Claude opens a Cygnix page; paste your API key and click Approve.
    If your organization has request headers instead: choose No sign-in, add header Authorization with value Bearer cyg_live_YOUR_KEY.
  4. In a chat, enable the connector from the tools menu and ask: “Use Cygnix SEO to check AI-search readiness for https://example.com”.

ChatGPT (web)

  1. Turn on Developer mode in Settings (Security and login → Developer mode; plan and workspace permissions apply).
  2. Open Plugins / Apps, click + then Add custom MCP server.
  3. Server URL: https://mcp.cygnixlabs.com/mcp. Authentication: OAuth. ChatGPT registers itself automatically.
  4. When the Cygnix page opens, paste your API key and approve. Then in a chat type @Cygnix SEO and ask, for example, “cluster these keywords: …”.

ChatGPT desktop and Codex can also send the key as a bearer token from an environment variable instead of OAuth.

Cursor

Add this to ~/.cursor/mcp.json (all projects) or .cursor/mcp.json (one project), then reload MCP servers in Settings → MCP.

{
  "mcpServers": {
    "cygnix-seo": {
      "url": "https://mcp.cygnixlabs.com/mcp",
      "headers": { "Authorization": "Bearer cyg_live_YOUR_KEY" }
    }
  }
}

Claude Code

One command (HTTP transport):

claude mcp add --transport http cygnix-seo https://mcp.cygnixlabs.com/mcp \
  --header "Authorization: Bearer cyg_live_YOUR_KEY"

Add --scope user to use it in every project. Check with claude mcp list, then run /mcp inside Claude Code.

VS Code (Copilot agent mode)

Create .vscode/mcp.json. VS Code prompts for the key once and stores it securely:

{
  "inputs": [
    { "type": "promptString", "id": "cygnix-key", "description": "Cygnix API key", "password": true }
  ],
  "servers": {
    "cygnix-seo": {
      "type": "http",
      "url": "https://mcp.cygnixlabs.com/mcp",
      "headers": { "Authorization": "Bearer ${input:cygnix-key}" }
    }
  }
}

Open the Chat view, switch to Agent mode and enable the Cygnix tools.

Any MCP client or the API

Transport: Streamable HTTP (stateless, JSON responses). Auth: Authorization: Bearer cyg_live_YOUR_KEY or X-Api-Key, or OAuth 2.1 (metadata at /.well-known/oauth-authorization-server, dynamic client registration, PKCE S256).

curl -s https://mcp.cygnixlabs.com/mcp \
  -H "Authorization: Bearer cyg_live_YOUR_KEY" -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"account_status","arguments":{}}}'

Prefer local? npx -y cygnix-seo-mcp runs the five core tools over stdio for free.
